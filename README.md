# 🍕 Food Express - Full-Stack Delivery Web Application

A lightweight, mobile-optimized full-stack food delivery web application built using **Python Flask**, **SQLite**, and **JavaScript**. Features real-time cart interaction, dynamic menu rendering, backend database order persistence, live order tracking, and an admin dashboard.

---

## 🌟 Key Features

- **Dynamic Menu Rendering:** Fetches menu items directly from the backend SQLite database.
- **Interactive Shopping Cart:** Real-time item additions and total price calculations via JavaScript.
- **Database Persistence:** Stores order details, customer addresses, and item lists with auto-generated unique Order IDs.
- **Live Order Tracking (`/track`):** Allows customers to check their order status using their unique Order ID.
- **Admin Dashboard (`/admin`):** Enables restaurant management to view live orders, total revenue, and customer delivery details.

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Database:** SQLite3
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Development Environment:** Pydroid 3 (Android)
